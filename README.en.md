# Create Fly Ponder Fix

[简体中文](./README.md) · English


Create Fly Ponder Fix is a small patch mod for Create Fly. It keeps certain Ponder scenes from aborting and fixes a deployer crash when the owner name is missing.

## In game

The patch covers missing side context in Ponder, an absent deployer OwnerName, and block-entity backup failure. It targets Create Fly `>=6.0.9-2 <6.0.10-0`.

## Installation

Download **v1.2.0+26.3** from [GitHub Releases](https://github.com/OpenRongMC/Create-Fly-Ponder-Fix/releases/tag/v1.2.0%2B26.3) for Minecraft Java **26.3** on **Fabric** with **Java 25**. Dependencies include [Create Fly](https://github.com/OpenRongMC/Create-Fly). Place the release JAR in the instance’s `mods/` directory. Use it only with a supported Create Fly version range as declared in the release JAR’s fabric.mod.json. For a server pack, follow its specified set of builds.
